# 📚 DBMS Notes

This repository contains my personal **Database Management System (DBMS)** notes that I am building while preparing for **placements, interviews, and computer science fundamentals**.

The goal of these notes is not just to memorize concepts, but to develop a strong understanding of how databases work internally and how DBMS concepts are applied in real-world systems.

## 🎯 Objectives

* Build a solid foundation in DBMS.
* Prepare for technical interviews and placements.
* Create a quick revision resource before exams and interviews.
* Maintain a single source of truth for everything I learn related to DBMS.

## 📌 Topics Covered

* Introduction to DBMS
* Database Architecture
* ER Model
* Relational Model
* Keys and Constraints
* SQL Basics and Advanced Queries
* Functional Dependencies
* Normalization (1NF, 2NF, 3NF, BCNF)
* Transactions and ACID Properties
* Schedules and Serializability
* Concurrency Control Protocols
* Locking Mechanisms
* Deadlocks
* Indexing and File Organization
* Recovery Techniques
* Distributed Databases
* Frequently Asked Interview Questions
* Previous Placement Questions
* Important Short Notes for Revision

## 📖 How I Use These Notes

* Learn concepts from lectures, books, and online resources.
